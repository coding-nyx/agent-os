# nyx-link daemon

Local WebSocket daemon that executes commands for the Forge module.

## Run

```
npm install
npm run dev
```

## Environment

- `NYX_LINK_PORT` (default: 4343)
- `NYX_LINK_ROOT` (default: repo root)
- `NYX_LINK_TIMEOUT_MS` (default: 8000)
- `NYX_LINK_MAX_BUFFER` (default: 204800)
