## 2026-03-13 - [UnifiedModulePage Mobile Height] **Learning:** Fixed height properties (like h-[600px]) on core wrapper components break mobile responsiveness when content exceeds the height, causing clipping. Use min-h-[600px] instead to allow content to grow while retaining desktop defaults (lg:h-auto lg:min-h-0). **Action:** Always prefer min-heights (min-h-[x]) over fixed heights (h-[x]) for main layout wrappers that will render dynamic or scrolling content on mobile.
