# Runtime integration decisions

Runtime source and exact revision are recorded in `compatibility.lock.json`. ARA is the product identity; upstream names, licenses and native file formats are preserved for attribution and compatibility. The downstream branch currently requires zero core patches.

| Area | Source inspected | Decision and relevant cases |
| --- | --- | --- |
| Execution | `hermes_cli/gateway_client.py`, `gateway/session_authority.py`, canonical contracts | Use the authenticated native client, durable creation/submission IDs and native epochs. Standalone web-server session RPC differs and is not the execution path. Disconnect is not cancellation. Control clients resume/attach before responding; native approval authority requires a subscribed viewer. Clarification uses `clarify.respond` with `answer`, separately from approval choices. |
| Tool discovery | `tools/tool_search.py`, `model_tools.py` | Preserve deferred schemas/search/describe/call. Do not flatten all tools into every prompt. The actual native harness integration test exercises discovery and the ARA MCP call. |
| Profiles | `hermes_cli/profiles.py` | Reuse native creation with `no_alias=True`; isolate homes and preserve bundled skills. Native config clones intentionally copy `.env`; an adapter wraps the native pre-publication layout seam to exclude borrowed credentials before the clone is discovered. ARA data configuration is also installed inside staging: immediate multiplexer adoption otherwise caches a profile before its MCP connection exists. A writable user-level alias directory is not required by the ARA API. |
| Auth | native OAuth routes, custom endpoints and `dashboard_auth/native_http.py` | ARA coordinates setup; native code stores/refreshes credentials. Per-request same-user HTTP tickets target the actual profile. Keys and refresh grants do not enter client state or ordinary exports. |
| Channels | `profile_channels.py`, messaging routes, native multiplexer | Use native adapters and targeted profile controls; validate Telegram identity before claiming a bot. Import/clone strips connection activation. Remote channel/runtime splitting remains explicitly uncertified. |
| Files and learning | native config, memory and profile routes | Preserve real SOUL/memory/skill packages and frozen-session behavior. Configure background review/write controls. Native gateway memory/skill review stages proposals instead of always blocking a turn; list/apply/reject use its pending store, native pinned-target appliers and conflicts. No weight-training claims or notification-flag substitute. |
| Audio | native audio routes and transcription/TTS providers | Use native transcription/speech endpoints; browser microphone/output capability is independent. Chained voice can feed a normal agent session. Real-time duplex/wake-word operation is not claimed by this prototype. |
| OpenClaw import | native `claw.py` and optional `openclaw_to_hermes.py` Migrator | Reuse upstream's detailed mappings, conflict handling and secret exclusions. Preview/apply are node operations; stage away from native discovery and deactivate bots/schedules before publication. |
| Native imports | native archive validation/import and channel-scrub helpers | Validate size/paths, import in staging, remove credentials/channel state and preserve source. An import does not authorize a duplicate bot or a running schedule. |
| Recovery | native WAL-safe full backup and restore helpers | Reuse native DB snapshots and integrity validation. Protect application/native archives with encryption. State explicitly that external services and workspaces require separate protection, and cross-store capture is not a distributed atomic snapshot. |
| Node sync | native consistent snapshot plus sanitized import/export | Passive encrypted host snapshots, durable local pending/ack status, hash checks and reconciliation. Active state is not shared between native homes. Credentials are not cloned by sync. |

Changes to this table accompany each integration change. Prefer a native implementation when it fits; add a focused patch only after a concrete gap is reproduced. Tests should verify behavior through real native imports and isolated homes, not assume docs and every entry point expose identical wire contracts.
