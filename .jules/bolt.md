## 2024-05-18 - [TaskCard memoization]
**Learning:** In list views that map large arrays of objects and support high-frequency interaction (like text search or real-time filtering), mapping complex unmemoized children like `TaskCard` dynamically causes continuous O(N) evaluation cascades.
**Action:** Always wrap list row child components (e.g. `TaskCard` inside `TaskManager`) with `React.memo`. When doing so, you must either pass strictly stable primitives (e.g., `taskId` instead of `task` with `useCallback` stabilized handlers) OR define a safe, explicit custom equality check (`(prevProps, nextProps)`) that ignores complex array props (`allTasks`) or inline callbacks ONLY if it is architecturally proven that the ignored callbacks solely invoke stable setters and do not risk stale closures. NEVER map a hook inside a loop (`rules-of-hooks` violation).
